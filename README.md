# Galactic App 🚀

Galactic Physics is an Android application project developed using Kotlin and Android Studio. The project uses Android's AppCompatActivity architecture and modern edge-to-edge UI support to establish the main application interface.

The application is designed around a space and physics-related theme, providing a foundation for an Android mobile application.

### Technologies Used

- Kotlin
- Android Studio
- Android SDK
- XML Layouts
- AndroidX Libraries

### Project Type

Android Mobile Application

### Development Environment

Android Studio
